About the Project

This project is a simple school management system built using Java. It does not handle every real-world school operation. The main purpose of this project is to practice:

Java fundamentals
Object-Oriented Programming (OOP)
Writing clean and understandable code
Class relationships
Basic data handling
Project structure and logic building

The system mainly manages:

Student details
Teacher details
Fees paid by students
Salary received by teachers
School earnings and expenses
Features
Student Management
Store student information
Track fees paid by students
View remaining fees
Teacher Management
Store teacher information
Manage teacher salaries
Track salary payments
School Finance Management
Track total money earned through student fees
Track money spent on teacher salaries
Calculate school balance
Technologies Used
Java
Object-Oriented Programming Concepts
Collections (ArrayList)
Basic Console Application
OOP Concepts Used

This project helped in understanding:

Classes and Objects

Data management using objects
